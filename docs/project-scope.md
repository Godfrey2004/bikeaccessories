
# RIDEFORGE — Project Scope

## 1. Project Objective
Build a motorcycle accessories shop website with an admin panel and an internal billing application.

## 2. In Scope — Phase 1
- Public home page
- Product listing, search and filtering
- Product details
- Shop contact information and location
- Secure admin authentication
- Product creation and editing
- Billing and invoice printing
- Shared product catalogue and inventory
- Stock updates when bills are finalized, subject to confirmed business rules

## 3. Out of Scope — Phase 1
- Customer registration and login
- Online shopping cart and checkout
- Online payment gateway
- Mobile application
- Advanced analytics and automated notifications

## 4. Assumptions
- Customers can browse without logging in.
- Only authorized staff can access admin and billing features.
- The website and billing application use the same product data.
- Tax, invoice and stock rules require client confirmation.

## 5. Success Criteria
- Customers can find and view products.
- Authorized staff can manage products.
- Staff can create, save and print bills.
- Inventory remains consistent with finalized bills.
- The application passes agreed functional and security tests.
